# Sistema de Gestión de Supermercado

Proyecto de Programación Avanzada. La aplicación conserva el backend de la Unidad II y agrega una interfaz de escritorio en Java Swing para la Unidad III.

## Ejecutar

- Abrir el proyecto en NetBeans y usar **Run Project**. Swing se inicia por defecto.
- Para usar el menú original de consola, ejecutar `cl.duocuc.supermercado.Main` con el argumento `--consola`.
- Gson está incluido en `lib/` y configurado como dependencia del proyecto. La vista **Productos** permite exportar el inventario a un archivo JSON.

El alcance del primer avance y los siguientes hitos está en [PLAN_UNIDAD_III.md](PLAN_UNIDAD_III.md).
