# Dependencia externa

- **Gson 2.15.0**, de Google, bajo licencia Apache 2.0.
- Se usa en la exportación del inventario a JSON desde la vista Productos.
- Origen: https://github.com/google/gson y Maven Central (`com.google.code.gson:gson:2.15.0`).
- La dependencia se referencia desde `nbproject/project.properties` para compilación y ejecución en NetBeans.
